# 双窗口舞台控制台（Rehearsal Stage Console）

一台电脑 + 双显示器 / 大屏的排练现场用：**大屏只出画面，操作台负责切段与音效**。单文件即用，无后端、无框架、纯 HTML5 原生播放。

在线地址：<https://gejx-gejingxuan.github.io/rehearsal-stage/>

## 使用

1. 打开在线地址，点「一键打开两个窗口」（也可分开打开）
   - 若浏览器拦了第二个窗口，用下面两个按钮分别打开
2. **大屏窗口**：第一次要选一次视频素材
   - 点「选择视频文件夹」选本机的 `win7-video` 文件夹，或直接把文件夹 / 视频 / 图片拖进窗口
   - 只想放几张图也行：直接把图片拖进去，不用先选视频
   - 也可以点「导入排练包（zip）」直接恢复上次打好包的片段与顺序
3. 再在**大屏窗口点一下画面**：这一次点击同时解锁声音与全屏
4. 之后全部用**控制台**操作；按 `Esc` 退出全屏

## 素材：图片、追加、顺序

- **视频 / 图片混排**：`mp4 m4v mov webm mkv avi / jpg jpeg png gif webp bmp avif` 都能进片段表
- **音频进音效板**：`mp3 m4a wav ogg oga flac aac opus weba` 加到音效板，不进片段表
- **图片按停留秒数走**：默认 5 秒，控制台「设置 → 图片停留」可改；到点后
  - 开了「连播」或「图片自动前进」→ 自动下一段；都没开 → 停在原地等你按下一个
- **随时追加，不用重开窗口**：已经开播后，再把新视频 / 新图片 / 音频拖进大屏或控制台窗口，或在
  - 大屏窗口点右下角「＋ 素材 / ＋ 文件夹」
  - 控制台 CUE 卡片的「＋ 素材 / ＋ 文件夹」（在控制台直接选文件，选完自动送到大屏）
  - 名字对得上旧片段的＝补素材；对不上的＝**接到片段表最后一段**并继续编号；已经在列表里的会跳过
- 片段顺序、编号、备注都在控制台 CUE 卡片上看，选中后可上移 / 下移
- **卡片自带缩略图**：大屏在后台静默抽帧（视频取最不黑的一帧、图片缩成小图），控制台卡片上就能看到每段长什么样；「设置 → 卡片缩略图」可关掉

## 音效素材（音频）

- 控制台音效板点「**＋ 音效**」选文件，或直接把音频拖进任意窗口；也可以走「＋ 素材 / ＋ 文件夹」
- 新音频立即出现在音效板，与默认音效一样点击播放、循环、调音量；同名音频不会重复加
- 音效按钮可**拖动排序**，拖到另一个按钮左侧 / 右侧即可插入，顺序会同步到播放端
- 导出排练包会把自定义音效一起打包，导入后音频与自定义标签一起恢复

## 片段级编辑（名称 / 音量 / 倍速）

- 在控制台 CUE 条上点选一个片段，下方「**片段编辑**」即可单独改名称
- **片段音量** 0~200%（默认 100%）：最终响度 = 主推子 × 片段音量，切到该段时自动套用
- **片段倍速** 0.25~4（留空 = 跟随全局倍速）；设置后切段会自动用这个速度
- 导出排练包时这些设置随片段一起保存，导入后原样恢复

## 音量（推子 0~200%）

- 主视频与音效各自一条推子，都能拉到 **200%**；超过 100% 时读数标黄
- 超过 100% 是真的变大：播放端自动接入一路 Web Audio 增益（元素 `volume` 上限只有 1）；100% 以下走原路径，行为不变
- 电平表抽头在增益前，读数不会因为放大而重复加倍；静音或推子归零仍然显示 `-∞`
- 音效板每条正在播放的音效都有**实时进度条**与 `当前 / 总长` 时间；循环音效带「循环」标记，播完或停止后自动隐藏
- 进度条支持**点击 / 按住拖动定位**，拖动时大屏音效跟着跳转，松手后继续播放
- 播放端按 `↑` `↓` 也能一路加到 200%

## 两个窗口

- **播放端（大屏）**：只负责画面与声音——片段、图片、音效、黑场、铺满、逐帧、AB 循环；全屏后**不显示任何提示浮层**
- **控制台（操作台）**：状态灯条、监视器预览、双 LED 电平表、走带面板（GO / 全停 / 大号时间码）、音效板、带缩略图的 CUE 片段条、设置与快捷键总表，深色 / 浅色可切换；CUE 条可拖拽排序 / 删除 / 一键清空（Ctrl+Z 撤销），进度条上标出 AB 起止点
- 两个窗口用 `BroadcastChannel` 互相同步：谁操作、另一边都跟着变；新素材文件直接递给大屏，不经过服务器

## 排练包（zip）

- 控制台顶栏「**导出包**」：把当前**片段顺序** + 每个片段的名称 / 音量 / 倍速 + 全部播放设置 + 控制台设置 + 视频 / 图片 + 音效 mp3 打包成 zip 下载
- 「**导入包**」：在控制台窗口选一个 zip 原样恢复（顺序一起回来，音效也从包里走）；包里带着的新素材会接在片段表后面
- 打包与导入全部在浏览器本机完成，**不上传任何服务器**

## 快捷键（播放端 / 控制台都可用）

| 按键 | 功能 |
| --- | --- |
| `1` `2` `3` `4` | 回到前面第 1~4 个片段 |
| `5` | 重播当前片段 |
| `6` `7` `8` `9` `0` | 跳到后面第 1~5 个片段 |
| 空格 / 单击画面 | 播放 / 暂停（图片＝继续 / 暂停计时） |
| `←` `→` | 快退 / 快进 5 秒 |
| `,` `.` | 后退 / 前进一帧 |
| `↑` `↓` / 滚轮 | 主视频音量 ±5%（最高 200%） |
| `Alt` + 左键 / 右键 | 上一个 / 下一个片段（大屏窗口直接切） |
| `M` / `X` | 主视频静音 / 停止全部音效 |
| `F` / `Esc` / 双击画面 | 全屏 / 退出全屏（全屏时鼠标静止 2.6 秒自动隐藏） |
| `B` / `T` | 黑场 / 铺满画面 |
| `L` / `C` | 循环 / 连播 |
| `I` | 添加素材（视频 / 图片） |

## 说明

- **设置会记住**：主视频 / 音效推子、倍速、循环 / 连播、铺满画面都存在本机（localStorage），刷新或重开窗口后自动恢复；静音与黑场出于安全不记忆

- **视频不进仓库**：素材约 572MB，网页版不内嵌视频；每次开新窗口需在大屏窗口选一次素材，或导入排练包
- 片段缺失时会自动跳到最近一个可用片段并提示，CUE 条始终按完整片段表编号
- 支持 mp4 / m4v / mov / webm / mkv 等常见视频，以及 jpg / png / gif / webp 等图片；老系统（Win7）建议用 H.264 版本的素材
- 白色单页网页版在另一个仓库：<https://gejx-gejingxuan.github.io/rehearsal-player/>
