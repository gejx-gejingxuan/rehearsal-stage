双窗口舞台控制台

大屏只出画面，操作在控制台。两个窗口各自独立，可放在两台显示器上。

播放端 · 大屏

只负责出画面与声音：片段与图片、音效、黑场、铺满、逐帧、AB 循环、电平表。 全屏后不显示任何提示文字。

控制台 · 操作台

两行顶栏与状态灯、监视器预览、双 LED 电平表、走带面板（GO / 全停 / 大号时间码）、 音效板、CUE 片段条、设置与快捷键总表，深色浅色可切换。

第一次使用（每次开新窗口都要做一次）
  1. 在大屏窗口点「选择视频文件夹」选本机的 win7-video 文件夹（也可直接把文件夹拖进窗口）；手里已经有排练包，就直接点「导入排练包（zip）」。
  2. 再在大屏窗口点一下画面：这一次点击同时解锁声音与全屏。
  3. 随时加新素材：已经开播后，再把新视频 / 新图片拖进大屏窗口，或在控制台 CUE 卡片点「＋ 素材」；名字对得上旧片段的＝补素材，对不上的＝接到片段表后面继续编号。
  4. 之后全部用控制台操作；按 Esc 退出全屏。
排练包（zip）：控制台顶栏「导出包」＝把当前片段顺序、全部设置和视频 / 图片（含音效）打包下载；「导入包」＝在控制台选一个 zip，原样恢复，播放顺序也一起回来。打包与导入都在本机完成。 素材只在本机读取，不会上传到任何服务器（视频体积大，不放进仓库）。
